## 0. One-paragraph design

A single plain-Ruby module `Onetime::RecentErrors` (`lib/onetime/recent_errors.rb`) owns ONE Redis list key (`recent_errors:ring`, LPUSH + LTRIM 0..99 + EXPIRE 7d in one MULTI — the exact `DispatchNotification#deliver_via_bell` pattern at `lib/onetime/operations/dispatch_notification.rb:132–136`, and the raw-`Familia.dbclient` key style of `ErrorHandler.track_error` at `lib/onetime/error_handler.rb:294–298`). It is writer AND reader (the `Onetime::ColonelAuditReader` idea: one module shared by the HTTP list, the HTTP detail and the CLI so field allowlists cannot drift). Three write points feed it: (W1) `ErrorHandler.safe_execute`'s non-Sentry branch; (W2) an Otto **handler wrapper** registered from `OttoHooks#configure_otto_request_hook` that sees every exception escaping a matched route, records it when the router has no registered handler for it, and re-raises so Otto's own 500 path is untouched; (W3) the Roda `/auth` `:error_handler` on any `status >= 500`. Reads: `GET /api/colonel/errors` (paginated, frozen envelope, `sentry_enabled` flag) and `GET /api/colonel/errors/:error_id`; console view `/colonel/errors`; CLI `ots errors list`. No mutations exist in this issue, so nothing is audited and nothing enters `destructive_actions.rb`.

Governing rule (see decisions): **the ring holds every exception this process did NOT ship to Sentry.** W1 is gated on `sentry_available?` (Sentry does receive those); W2 and W3 are NOT gated because neither Otto nor Roda sets `env['rack.exception']`, so `Sentry::Rack::CaptureExceptions` (`lib/onetime/application/middleware_stack.rb:746`) never sees them on any install.

## 1. Store + reader: `lib/onetime/recent_errors.rb`

```ruby
# lib/onetime/recent_errors.rb
# frozen_string_literal: true
require 'json'
require 'securerandom'
require_relative 'logger_methods'
require_relative 'operations/email/error_scrub'   # provider-credential shapes (no deps)

module Onetime
  module RecentErrors
    extend Onetime::LoggerMethods
    extend self

    KEY                  = 'recent_errors:ring'
    MAX_ENTRIES          = 100
    RETENTION_DAYS       = 7
    RETENTION            = RETENTION_DAYS * 24 * 60 * 60
    MAX_MESSAGE_LENGTH   = 500
    MAX_OPERATION_LENGTH = 200
    MAX_LOCATION_LENGTH  = 200
    SOURCES              = %w[safe_execute otto auth].freeze
    FIELDS               = %i[id at error_class message operation request_id error_type source location].freeze

    EMAIL_PATTERN      = /[A-Za-z0-9._%+\-]+@[A-Za-z0-9.\-]+\.[A-Za-z]{2,}/
    LONG_TOKEN_PATTERN = /\b[A-Za-z0-9_\-]{32,}\b/     # secret keys, api tokens, session ids
    CONTROL_PATTERN    = /[[:cntrl:]]+/
    REDACTED_EMAIL     = '[email]'
    REDACTED_TOKEN     = '[token]'

    # Best-effort. NEVER raises. Returns the stored entry Hash or nil.
    def record(exception, operation:, source:, request_id: nil, error_type: nil)
      return nil unless Familia.dbclient
      entry = build_entry(exception, operation:, source:, request_id:, error_type:)
      json  = JSON.generate(entry)
      Familia.dbclient.multi do |multi|          # keep resolve + multi on one line/pool checkout (see dispatch_notification.rb:129-131 comment)
        multi.lpush(KEY, json)
        multi.ltrim(KEY, 0, MAX_ENTRIES - 1)
        multi.expire(KEY, RETENTION)
      end
      entry
    rescue StandardError => ex
      app_logger.error 'recent-errors: record failed', { exception: ex, operation: 'recent_errors.record' }
      nil
    end

    def count = Familia.dbclient.llen(KEY)
    def recent(limit: MAX_ENTRIES) = parse(Familia.dbclient.lrange(KEY, 0, [limit, MAX_ENTRIES].min - 1))
    # Index-backed page (LRANGE), newest first. total_count is LLEN — exact, never capped.
    def page(page:, per_page:)
      start = (page - 1) * per_page
      { entries: parse(Familia.dbclient.lrange(KEY, start, start + per_page - 1)), total_count: count }
    end
    def find(id) = recent.find { |e| e['id'] == id }
    def clear! = Familia.dbclient.del(KEY)               # tests only
    def format_entry(entry) = FIELDS.to_h { |f| [f, entry[f.to_s]] }   # explicit allowlist, symbol keys

    private

    def build_entry(exception, operation:, source:, request_id:, error_type:)
      {
        'id'          => SecureRandom.hex(8),
        'at'          => Familia.now.to_f,
        'error_class' => exception.class.name.to_s,
        'message'     => sanitize_message(exception.message),
        'operation'   => sanitize_operation(operation),
        'request_id'  => request_id&.to_s&.slice(0, 64),
        'error_type'  => error_type&.to_s&.slice(0, 64),
        'source'      => SOURCES.include?(source.to_s) ? source.to_s : 'otto',
        'location'    => location_for(exception),
      }
    end

    # plain text, no control chars, no emails, no provider credentials, no long tokens, <= 500
    def sanitize_message(text)
      s = OT::Utils.utf8_safe(text.to_s).gsub(CONTROL_PATTERN, ' ')
      s = Onetime::Operations::Email::ErrorScrub.redact(s)
      s = s.gsub(EMAIL_PATTERN, REDACTED_EMAIL).gsub(LONG_TOKEN_PATTERN, REDACTED_TOKEN)
      s.squeeze(' ').strip.slice(0, MAX_MESSAGE_LENGTH)
    end
    def sanitize_operation(text) = OT::Utils.utf8_safe(text.to_s).gsub(CONTROL_PATTERN, ' ').strip.slice(0, MAX_OPERATION_LENGTH)

    # First backtrace frame under the app root, as "relative/path.rb:LINE". Never the whole backtrace.
    def location_for(exception)
      home  = Onetime::HOME.to_s
      frame = Array(exception.backtrace).find { |f| f.start_with?(home) }
      return nil unless frame
      frame.sub("#{home}/", '').sub(/:in .*\z/, '').slice(0, MAX_LOCATION_LENGTH)
    rescue StandardError
      nil
    end

    def parse(raw) = Array(raw).filter_map { |j| JSON.parse(j) rescue nil }.select { |e| e.is_a?(Hash) && e['id'] }
  end
end
```

Notes: `OT::Utils.utf8_safe(text, replacement: '')` exists at `lib/onetime/utils/strings.rb:204` (call form `OT::Utils.utf8_safe(...)` as in `lib/onetime/cli/customers/diagnose_command.rb:215`). `ErrorScrub.redact` is at `lib/onetime/operations/email/error_scrub.rb:41` and has no dependencies. `Familia.now` is used the same way in `try/integration/api/colonel/get_colonel_stats_try.rb:39`.

```ruby
# lib/onetime/application/unhandled_error_recorder.rb
# frozen_string_literal: true
require_relative '../recent_errors'
require_relative 'error_correlation'

module Onetime
  module Application
    # #4350. Otto#call (otto.rb:154) rescues StandardError and swallows it into
    # Otto::Core::ErrorHandler#handle_error, which offers no hook and never
    # sets env['rack.exception'] — so neither a Rack middleware above the
    # router nor Sentry::Rack::CaptureExceptions ever sees an unhandled route
    # exception. A handler wrapper composes INSIDE the router, around every
    # matched route (outermost of RouteAuthWrapper), so it is the one public
    # Otto seam that sees the exception with env in hand. It records and
    # RE-RAISES: Otto's own 500 response, log line and backtrace are untouched.
    module UnhandledErrorRecorder
      extend self

      class Wrapper
        def initialize(inner_handler, route_definition, router)
          @inner_handler, @route_definition, @router = inner_handler, route_definition, router
        end

        def call(env, *)
          @inner_handler.call(env, *)
        rescue StandardError => ex
          record(ex, env) unless handled_by_router?(ex)
          raise
        end

        private

        # Mirrors Otto::Core::ErrorHandler#find_error_handler (ancestor walk)
        # over the PUBLIC `error_handlers` reader (otto.rb:83): a typed error
        # with a registered handler (404/403/422/429/503...) is not "the app
        # throwing" and is never recorded.
        def handled_by_router?(ex)
          ex.class.ancestors.any? { |k| k.is_a?(Class) && @router.error_handlers.key?(k.name) }
        end

        def record(ex, env)
          # DECLARED PATTERN, never PATH_INFO: `/secret/:key` not `/secret/abc123`.
          operation = "#{@route_definition.verb} #{env['SCRIPT_NAME']}#{@route_definition.path}"
          # Stash otto.error_type so RequestLogger names the failure (today an
          # unhandled 500 logs with no error_type). Body is a throwaway.
          Onetime::Application::ErrorCorrelation.apply({}, env, ex)
          Onetime::RecentErrors.record(
            ex,
            operation: operation,
            source: 'otto',
            request_id: env[Onetime::Application::ErrorCorrelation::ENV_REQUEST_ID],
            error_type: Onetime::Application::ErrorCorrelation.short_class_name(ex),
          )
        rescue StandardError
          nil # a recorder must never change which exception the client sees
        end
      end

      def register(router)
        router.register_handler_wrapper do |route_definition, inner_handler|
          Wrapper.new(inner_handler, route_definition, router)
        end
      end
    end
  end
end
```
`RouteDefinition#verb` is a Symbol (`:GET`, route_definition.rb:48) and `#path` the pattern string (`:21`); `env['SCRIPT_NAME']` is the URLMap mount prefix (`/api/colonel`), so operation reads `GET /api/colonel/secrets/:secret_id`.

```ruby
require 'json'
require 'onetime/recent_errors'
module Onetime; module CLI
  module Errors
    DEFAULT_LIMIT = 50
    FORMATS       = %w[text json].freeze
    class ListCommand < Command
      desc 'List recent application errors (newest first)'
      option :limit,  type: :integer, default: DEFAULT_LIMIT, aliases: ['n'], desc: "Maximum entries (default #{DEFAULT_LIMIT}, ring holds #{Onetime::RecentErrors::MAX_ENTRIES})"
      option :format, type: :string,  default: 'text', aliases: ['f'], desc: "Output format: #{FORMATS.join(', ')}"
      def call(limit: DEFAULT_LIMIT, format: 'text', **)
        boot_application!
        unless FORMATS.include?(format) then warn "Unknown format '#{format}'. Use one of: #{FORMATS.join(', ')}"; exit 1; end
        entries = Onetime::RecentErrors.recent(limit: limit.to_i).map { |e| Onetime::RecentErrors.format_entry(e) }
        format == 'json' ? puts(JSON.pretty_generate(entries)) : print_table(entries)
      end
      private
      def print_table(entries)   # audit_command.rb:137-160 shape
        return puts('No errors recorded.') if entries.empty?
        puts format('%-20s %-34s %-40s %s', 'When (UTC)', 'Class', 'Operation', 'Request id'); puts '-' * 110
        entries.each do |row|
          puts format('%-20s %-34s %-40s %s', timestamp(row[:at]), clip(row[:error_class], 34), clip(row[:operation], 40), row[:request_id] || '-')
          puts "    #{clip(row[:message], 100)}" unless row[:message].to_s.empty?
          puts "    at #{row[:location]}" if row[:location]
        end
      end
      # timestamp/clip: copy audit_command.rb:162-171
    end
  end
  class ErrorsCommand < Command   # `ots errors` usage, mirrors AuditCommand (audit_command.rb:187-212)
    desc 'Read the recent application-error ring'
    def call(**)
      boot_application!
      puts 'Recent application errors'; puts '-' * 70
      puts "Retained: #{Onetime::RecentErrors.count} of #{Onetime::RecentErrors::MAX_ENTRIES} (#{Onetime::RecentErrors::RETENTION_DAYS}-day retention)"
      puts "Sentry (diagnostics): #{Onetime.d9s_enabled ? 'enabled — safe_execute failures ship there instead' : 'disabled — this ring is the only in-app trace'}"
      puts; puts 'Usage: ots errors list [--limit N] [--format text|json]'
    end
  end
  register 'errors', ErrorsCommand
  register 'errors list', Errors::ListCommand
end; end
```

# DECISIONS
## Premise corrections (the code does not match the issue/map/scope)

1. **There is no "generic 500 handler" in `otto_hooks.rb`.** The map (§C) and the scope ("(2) the global unhandled-exception path in otto_hooks.rb — the generic 500 handler") point at a write point that does not exist: `configure_otto_request_hook` registers only typed handlers (404/422/403/429/503, lines 56–238). Unhandled exceptions are rescued by `Otto#call` (`otto-2.10.0/lib/otto.rb:154`) and swallowed into `Otto::Core::ErrorHandler#handle_error` (`error_handler.rb:13–76`), which has no hook. Decision: use Otto's public `register_handler_wrapper` seam (already used by `NetworkRequirements`, `network_requirements.rb:85–98`) and the public `error_handlers` reader (`otto.rb:83`) to record-and-re-raise. Rejected alternatives: (a) registering a `StandardError` handler — Otto's `find_error_handler` walks ancestors so it would work, but it reroutes every 500 through `handle_expected_error`, which logs "Expected error in request" at `:error` WITHOUT a backtrace and drops the custom `/500` route lookup — a logging regression; (b) prepending onto `Otto#handle_error` — private-API monkey patch; (c) a Rack middleware — cannot see the exception (Otto swallows it, sets no `rack.exception`) and would also need a `middleware_manifest_spec.rb` change.

2. **Sentry does NOT receive Otto- or Roda-unhandled 500s today, on any install.** `Sentry::Rack::CaptureExceptions` (mounted at `middleware_stack.rb:746`) captures only re-raised exceptions or `env['rack.exception']`/`env['sinatra.error']` (`sentry-ruby .../rack/capture_exceptions.rb:34–41, 52–54`). Otto sets neither; Roda's `:error_handler` plugin sets neither; no logger appender forwards to Sentry (`setup_loggers.rb` mounts only IO + audit syslog appenders); `Otto.logger` is a plain SemanticLogger (`setup_loggers.rb:362`). So the issue's premise "exceptions either ship to Sentry or leave no readable trace" is wrong for unhandled route errors: they leave a log line only, in BOTH postures. Decision: the scope's "write only when `sentry_available?` is false" is honoured where its premise holds (W1 `safe_execute`, which does capture to Sentry) and NOT applied to W2/W3, where gating would leave a Sentry-enabled install with no trace at all. Stated rule: the ring holds every exception this process did not ship to Sentry. The `sentry_enabled` flag and the console copy describe exactly this split.

3. **`Core::Middleware::ErrorHandling` (`apps/web/core/application.rb:53`) cannot see route exceptions.** `Base.use` middleware is mounted by `Rack::Builder` ABOVE `builder.run router` (`lib/onetime/application/base.rb:174–199`), i.e. outside Otto's rescue, so its `rescue StandardError` → `Sentry.capture_exception` path (`error_handling.rb:32, 156`) is unreachable for anything a route raises. Not fixed here (out of scope), but it is why W2 must live inside the router; noted for a follow-up issue.

4. **The map's `ErrorCorrelation` line numbers are right; its "second write point" is not.** `ErrorCorrelation.apply` (`error_correlation.rb:83–95`) runs only inside registered typed handlers, so an unhandled 500 today carries no `otto.error_type` in the request log. W2 calls `ErrorCorrelation.apply({}, env, ex)` to close that gap as a side benefit.

## Design decisions

5. **Plain module `Onetime::RecentErrors`, not a `Familia::Horreum`.** One raw key over `Familia.dbclient` (precedents: `ErrorHandler.track_error` `error_handler.rb:294–298`, `DispatchNotification` `dispatch_notification.rb:132–136`). A Horreum with no fields/identifier buys nothing; one module being writer + reader + allowlist is the `ColonelAuditReader` lesson (three readers, one FIELDS). Name is `RecentErrors` (plural, module) — the scope allowed "or similar".

6. **List ring (`LPUSH`/`LTRIM`/`EXPIRE` in one `MULTI`), MAX 100, 7-day TTL refreshed on write** exactly as scoped. Pagination is index-backed (`LRANGE` offset), `total_count` is `LLEN` (exact; no `capped`).

7. **Extra field `location`** (first backtrace frame under `Onetime::HOME`, relative `file:line`, ≤200 chars, never the full backtrace). Not in the scope's field list; added because "which line threw" is the single most actionable datum for "is the app throwing?", it contains no request data, and it costs one method. Everything else in the entry is exactly the scoped set: `id, at, error_class, message, operation, request_id, error_type` plus `source` (which write point).

8. **Operation for Otto errors is the declared route PATTERN with the mount prefix** (`GET /api/colonel/secrets/:secret_id`), never `PATH_INFO`: the raw path can carry a secret key or token as a segment (bearer material — same reasoning as `safe_request_context` never including the query string). For `/auth` the raw path is used because Rodauth keys travel in params; for `safe_execute` it is the operation name.

9. **Message sanitisation is a pipeline of existing pieces + two local regexes:** `OT::Utils.utf8_safe` → control-char strip → `Operations::Email::ErrorScrub.redact` (provider credential shapes, `error_scrub.rb:24–29`) → email regex → 32+-char token regex → 500-char truncation. The two existing email redactors (`mail/delivery/smtp2go.rb:150`, `utils/strings.rb:319 mask_email_address`) are provider/single-address scoped, so a local pattern is simpler than forcing either to fit. Caller context hashes from `safe_execute` are never forwarded (they carry account ids).

10. **No access-audit event** for the list, the detail or the CLI (scope: no PII). Contrast `audit list`, which records because the audit trail is itself sensitive. Nothing in #4350 mutates, so `destructive_actions.rb` is untouched and no `AuditedFailure`/`AuditReason` plumbing applies.

11. **Detail route `GET /errors/:error_id` included** ("if cheap"): `LRANGE 0 99` + find. 404 via `raise_not_found` → `Onetime::RecordNotFound` → the registered 404 handler (`otto_hooks.rb:61`). The console drawer uses the row already in hand; the route exists for deep links and CLI parity.

12. **W3 (Roda `/auth`) is in scope.** The scope names "the global unhandled-exception path"; `/auth` is one of the two routing stacks with its own unhandled path (`router.rb:101–115`), already sharing `ErrorCorrelation`. Three added lines; covered by extending the existing `router_error_shape_spec.rb` stub app.

13. **`sentry_enabled` = `Onetime.d9s_enabled`** (config intent), per the scope and matching the flag that mounts `CaptureExceptions`; the runtime `sentry_available?` stays private to `ErrorHandler` and only gates W1.

14. **Nav placement:** `platform` group beside `system` (`sections.ts:115–122`), icon `exclamation-triangle` (verified present in `HeroiconsSprites.vue`); the scope's "system/observability nav group" maps to `platform` — `ConsoleGroup` has no observability band and adding one for a single entry violates the "group of one reads as clutter" rule in `sections.ts:46–49`.

15. **No filters on the list endpoint.** The ring is ≤100 rows; server-side filters would add code paths for a set the console can already scan on one page (per_page 100).

16. **Retention/capacity are constants, not config** — same stance as `ColonelAuditEvent::MAX_EVENTS` ("no external configuration dependency", `colonel_audit_event.rb` cap comments).
